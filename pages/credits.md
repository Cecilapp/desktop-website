# Credits

Cecil Desktop is designed and developed by [Arnaud Ligny](https://arnaudligny.fr) ([Aperture Lab](https://aperturelab.fr)), the creator of [Cecil](https://cecil.app).

Developed with the help of [Claude Code](https://claude.com/product/claude-code).

The app stands on the shoulders of many open source projects: thanks to their authors and contributors.

## The app

| Project | Role |
|---------|------|
| [Cecil](https://cecil.app) | The static site generator at the heart of the app: build, preview, diagnosis and themes. |
| [PHP](https://www.php.net) | The language of the app, embedded: there is nothing to install. |
| [NativePHP](https://nativephp.com) | Turns the PHP app into a native desktop app (windows, menus, notifications, updates). |
| [Electron](https://www.electronjs.org) | The desktop runtime used by NativePHP, with [electron-builder](https://www.electron.build) for the installers and the updates. |
| [Laravel](https://laravel.com) | The PHP framework of the app. |
| [Livewire](https://livewire.laravel.com) | The reactive interface, written in PHP. |
| [Flux](https://fluxui.dev) | The interface components. |
| [Tailwind CSS](https://tailwindcss.com) | The styles of the interface. |
| [Heroicons](https://heroicons.com) | The icons. |
| [CodeMirror](https://codemirror.net) | The Markdown and YAML editor. |
| [Vite](https://vite.dev) | The front-end build tool. |
| [SQLite](https://sqlite.org) | The local database (sites, history). |
| [AWS SDK for PHP](https://aws.amazon.com/sdk-for-php/) | Publication to Amazon S3. |
| [Composer](https://getcomposer.org) | The PHP dependencies, and the themes from [Packagist](https://packagist.org). |
