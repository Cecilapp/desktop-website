# Cecil Desktop Pro

Cecil Desktop est gratuit pour 1 site. **Cecil Desktop Pro** est une licence pour aller plus loin, et soutenir le développement de Cecil.

:::info
Pendant la bêta, toutes les fonctions sont disponibles sans licence.
:::

## Version gratuite et Pro

| | Gratuite | Pro |
|-|----------|-----|
| Sites | 1 (+ les sites ouverts en mode Rédaction par leur profil) | Illimités |
| Cibles de publication par site | 1 | Plusieurs (production, préproduction…) |
| Build, preview, édition du contenu, médias, thèmes | ✓ | ✓ |
| Diagnostics : configuration, front matter, cache | ✓ | ✓ |
| [Diagnostics : SEO et liens](build-preview-diagnosis.md#diagnostic) | | ✓ |
| [Formulaire du schéma de pages](content.md#schema-de-pages) | En mode Rédaction | ✓ |
| [Mode Rédaction](writing-mode.md), ouverture d'un site en mode Rédaction pour tout le monde | ✓ | ✓ |
| [Profil de rédaction](writing-mode.md#confier-un-site-a-un-redacteur) : sections modifiables, droits sur les pages, cibles partagées | | ✓ |

Les fonctions Pro sont signalées dans l'application par un badge **Pro**. Sans licence, rien de ce que vous avez déjà ne vous est retiré : vos sites et vos cibles restent utilisables, seul l'ajout est limité.

## Prix

**49 €, en paiement unique** : une licence perpétuelle, avec **1 an de mises à jour**, sur **3 ordinateurs**. Achetez-la depuis la [section tarifs](/fr/#pricing) du site, ou depuis **Aide › Cecil Desktop Pro…** dans l'application.

Le paiement est géré par [Polar](https://polar.sh), qui envoie la clé de licence par e-mail.

## Activer la licence

1. Ouvrez **Préférences › Licence** (`Ctrl/⌘+,`).
2. Collez votre **Clé de licence**, reçue par e-mail après l'achat (elle est aussi dans le portail client).
3. Cliquez sur **Activer** : la clé est vérifiée en ligne, puis enregistrée chiffrée avec le trousseau du système.

![Les préférences Licence, pour saisir la clé de licence](/images/screenshots/license.png)

La carte de la licence affiche alors votre nom, la date d'achat, les versions couvertes par vos mises à jour et cet ordinateur.

## Vérifier et déplacer la licence

- La licence est vérifiée à nouveau en arrière-plan chaque semaine. Hors ligne, elle continue de fonctionner **30 jours** : au-delà, connectez-vous à Internet et cliquez sur **Vérifier**.
- Pour déplacer la licence sur un autre ordinateur, cliquez sur **Désactiver cette machine** (une connexion à Internet est nécessaire), puis activez-la sur l'autre.
- Si la licence est déjà active sur 3 ordinateurs, désactivez-en un depuis le **Portail client**, qui donne aussi accès à vos clés et à vos factures.
- **Changer de clé** remplace la clé, par ex. après un renouvellement.

## Après l'année de mises à jour

Votre licence est perpétuelle : les fonctions Pro restent disponibles dans toutes les versions publiées pendant votre année de mises à jour.

Les versions publiées ensuite fonctionnent comme la version gratuite, sans rien vous retirer. Avant que vous en installiez une, le bouton de mise à jour de la barre d'état vous prévient que les fonctions Pro n'y seront pas disponibles. Pour les retrouver, **Renouveler les mises à jour** : le renouvellement donne une nouvelle clé, à saisir dans **Préférences › Licence**. Vous pouvez aussi réinstaller une version publiée pendant votre année de mises à jour.

## Dépannage

| Message | Que faire |
|---------|-----------|
| *Cette clé de licence n'est pas valide.* | Vérifiez la clé, telle que reçue par e-mail. |
| *…le nombre maximal de machines.* | Désactivez un ordinateur depuis le portail client. |
| *Impossible de joindre desktop.cecil.app.* | Vérifiez votre connexion à Internet, puis réessayez. |
| *Licence à vérifier* | La licence n'a pas pu être vérifiée depuis plus de 30 jours : connectez-vous à Internet, puis cliquez sur **Vérifier**. |
| *Licence invalide* | La licence a été remboursée, révoquée, ou cet ordinateur a été désactivé depuis le portail : saisissez une autre clé, ou activez-la à nouveau. |
