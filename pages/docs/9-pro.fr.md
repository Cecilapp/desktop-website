# Cecil Desktop Pro

Cecil Desktop est gratuit, pour tous vos sites. **Cecil Desktop Pro** ajoute des fonctions pour les freelances et les agences qui gèrent les sites de leurs clients, et soutient le développement de Cecil.

:::info
Pendant la bêta, toutes les fonctions sont disponibles sans licence.
:::

## Version gratuite et Pro

| | Gratuite | Pro |
|-|----------|-----|
| Sites | Illimités | Illimités, dont 5 [sites Pro](#sites-pro) (+5 par pack) |
| Cibles de publication par site | 1 | Plusieurs sur les sites Pro (production, préproduction…) |
| Build, preview, édition du contenu, médias, thèmes | ✓ | ✓ |
| Diagnostics : configuration, front matter, cache | ✓ | ✓ |
| [Diagnostics : SEO et liens](build-preview-diagnosis.md#diagnostic) | | Sites Pro |
| [Formulaire du schéma de pages](content.md#schema-de-pages) | En mode Rédaction | Sites Pro |
| [Synchronisation Git](git.md) : ouverture d'un site depuis son dépôt, état, Récupérer et Envoyer, résolution des conflits | ✓ | ✓ |
| [Mode Rédaction](writing-mode.md), ouverture d'un site en mode Rédaction pour tout le monde | ✓ | ✓ |
| [Profil de rédaction](writing-mode.md#confier-un-site-a-un-redacteur) : sections modifiables, droits sur les pages, cibles partagées | | Sites Pro |

Les fonctions Pro sont signalées dans l'application par un badge **Pro**. Sans licence, ou sur un site qui n'est pas un site Pro, rien de ce que vous avez déjà ne vous est retiré : vos sites et vos cibles restent utilisables, seul l'ajout est limité.

## Sites Pro

Une licence Pro donne **5 sites Pro** : les fonctions Pro s'y appliquent, et vos autres sites gardent les fonctions de la version gratuite. Vous choisissez vos sites Pro dans l'application, et pouvez en changer : un emplacement libéré peut être réattribué à un autre site **30 jours** plus tard.

Pour gérer plus de sites clients avec les fonctions Pro, ajoutez des **packs de 5 sites Pro**.

Les rédacteurs d'un site Pro profitent de son profil de rédaction sans licence : seul le responsable du site a besoin de Pro.

## Prix

**59 € par an**, par utilisateur : un abonnement annuel, avec **toutes les mises à jour**, sur **3 ordinateurs**. Chaque pack de 5 sites Pro supplémentaires coûte **29 € par an**. Abonnez-vous depuis la [section tarifs](/fr/#pricing) du site, ou depuis **Aide › Cecil Desktop Pro…** dans l'application.

L'abonnement se renouvelle automatiquement chaque année, et se résilie à tout moment depuis le **Portail client**. Le paiement est géré par [Polar](https://polar.sh), qui envoie la clé de licence par e-mail.

## Activer la licence

1. Ouvrez **Préférences › Licence** (`Ctrl/⌘+,`).
2. Collez votre **Clé de licence**, reçue par e-mail après l'achat (elle est aussi dans le portail client).
3. Cliquez sur **Activer** : la clé est vérifiée en ligne, puis enregistrée chiffrée avec le trousseau du système.

![Les préférences Licence, pour saisir la clé de licence](/images/screenshots/license.png "Préférences Licence")

La carte de la licence affiche alors votre nom, la date de renouvellement de l'abonnement, vos sites Pro et cet ordinateur.

## Vérifier et déplacer la licence

- La licence est vérifiée à nouveau en arrière-plan chaque semaine. Hors ligne, elle continue de fonctionner **30 jours** : au-delà, connectez-vous à Internet et cliquez sur **Vérifier**.
- Pour déplacer la licence sur un autre ordinateur, cliquez sur **Désactiver cette machine** (une connexion à Internet est nécessaire), puis activez-la sur l'autre.
- Si la licence est déjà active sur 3 ordinateurs, désactivez-en un depuis le **Portail client**, qui donne aussi accès à vos clés, à votre abonnement et à vos factures.
- **Changer de clé** remplace la clé, par ex. pour utiliser une autre licence.

## Fin de l'abonnement

Si vous résiliez l'abonnement, ou s'il n'est pas renouvelé, les fonctions Pro restent disponibles jusqu'à la fin de la période payée.

Ensuite, Cecil Desktop fonctionne comme la version gratuite, sans rien vous retirer : vos sites, vos cibles et vos profils de rédaction restent utilisables, seul l'ajout est limité. Abonnez-vous à nouveau pour retrouver les fonctions Pro.

## Dépannage

| Message | Que faire |
|---------|-----------|
| *Cette clé de licence n'est pas valide.* | Vérifiez la clé, telle que reçue par e-mail. |
| *…le nombre maximal de machines.* | Désactivez un ordinateur depuis le portail client. |
| *Impossible de joindre desktop.cecil.app.* | Vérifiez votre connexion à Internet, puis réessayez. |
| *Licence à vérifier* | La licence n'a pas pu être vérifiée depuis plus de 30 jours : connectez-vous à Internet, puis cliquez sur **Vérifier**. |
| *Licence invalide* | L'abonnement a pris fin, la licence a été remboursée ou révoquée, ou cet ordinateur a été désactivé depuis le portail : abonnez-vous à nouveau, saisissez une autre clé, ou activez-la à nouveau. |
