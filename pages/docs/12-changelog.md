# Changelog

The new features and the fixes of each version of Cecil Desktop, the latest first. Each version embeds the latest version of [Cecil](https://cecil.app) at the time of its release.

To get the latest version, see [Updates](getting-started.md#updates). In the app, **Help › What's New** opens the notes of the installed version.
