# Cecil Desktop documentation

Cecil Desktop is a desktop app to manage your [Cecil](https://cecil.app) static sites: create them, edit their content, build, preview and publish them, without typing a single command. PHP and Cecil are embedded: there is nothing else to install.

New to Cecil Desktop? Start with [Getting started](getting-started.md): install the app and open your first site in a few minutes.

:::info
This documentation is about the app. To learn how a Cecil site works (content, templates, configuration), see the [Cecil documentation](https://cecil.app/documentation/).
:::

## Help and feedback

Found a bug, or missing something? In the app, use **Help › Send feedback…**: your message is sent to the team, with the versions of the app and of your system.
