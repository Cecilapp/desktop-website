# Keyboard shortcuts

The shortcuts of the menus are also shown in the [command palette](getting-started.md#find-your-way-around) (`Ctrl/⌘+K`), next to each action.

## Menus

| Action | Windows | macOS |
|--------|---------|-------|
| **File › Open folder…** | `Ctrl+O` | `⌘O` |
| **File › New site…** | `Ctrl+N` | `⌘N` |
| **File › Save** | `Ctrl+S` | `⌘S` |
| **File › Preferences** | `Ctrl+,` | `⌘,` |
| **Site › Start or open preview** | `Ctrl+P` | `⌘P` |
| **Site › Build** | `Ctrl+Shift+B` | `⌘⇧B` |
| **Site › Publish** | `Ctrl+Shift+P` | `⌘⇧P` |
| **Site › Open site folder** | `Ctrl+Shift+E` | `⌘⇧E` |
| **Site › Overview** | `Ctrl+1` | `⌘1` |
| **Site › Content** | `Ctrl+2` | `⌘2` |
| **Site › Media** | `Ctrl+3` | `⌘3` |
| **Site › Themes** | `Ctrl+4` | `⌘4` |
| **Site › Publishing** | `Ctrl+5` | `⌘5` |
| **Site › Configuration** | `Ctrl+6` | `⌘6` |
| **View › Command palette…** | `Ctrl+K` | `⌘K` |
| **View › Sidebar** | `Ctrl+B` | `⌘B` |
| **View › Output panel** | `Ctrl+J` | `⌘J` |
| **View › Focus mode** | `Ctrl+Shift+Enter` | `⌘⇧Enter` |

In [Writing mode](writing-mode.md), the sections the writer doesn't see are left out, but the others keep their shortcut (e.g. `Ctrl/⌘+2` for **Content**).

## Markdown editor

| Action | Windows | macOS |
|--------|---------|-------|
| **Bold** | `Ctrl+B` | `⌘B` |
| *Italic* | `Ctrl+I` | `⌘I` |
| Inline code | `Ctrl+E` | `⌘E` |
| Leave the focus mode | `Esc` | `Esc` |

In the editor, `Ctrl/⌘+B` makes the text bold instead of folding the sidebar.

## Lists

| Where | Action | Windows | macOS |
|-------|--------|---------|-------|
| **Sites** screen | Move from one site to another | Arrows | Arrows |
| | Open the site | `Enter` | `Enter` |
| | Remove the site from the list | `Delete` | `Delete` |
| Pages tree | Move in the tree, open or close a folder | Arrows | Arrows |
| | Rename the page | `F2` | `F2` |
| | Duplicate the page | `Ctrl+D` | `⌘D` |
| | Move the page to the trash | `Delete` | `⌘⌫` |
| Command palette | Choose an action | `↑` `↓` then `Enter` | `↑` `↓` then `Enter` |
| | Close the palette | `Esc` | `Esc` |

## Panes

The separators between the panes (pages tree, editor, Output panel…) can be moved with the keyboard: give them the focus with `Tab`, then use the arrows (with `Shift` for bigger steps).
