# Nouveautés

Les nouvelles fonctionnalités et les corrections de chaque version de Cecil Desktop, la plus récente en premier. Chaque version embarque la dernière version de [Cecil](https://cecil.app) au moment de sa sortie.

Pour obtenir la dernière version, voir [Mises à jour](getting-started.md#mises-a-jour). Dans l'application, **Aide › Nouveautés** ouvre les notes de la version installée.

:::info
Les notes de version sont rédigées en anglais.
:::
