# Préférences

Les **Préférences** (`Ctrl/⌘+,`, ou **Fichier › Préférences**) s'ouvrent dans leur propre fenêtre. Il n'y a pas de bouton d'enregistrement : les changements s'appliquent immédiatement.

![Les préférences générales : langue, thème et démarrage](/images/screenshots/preferences.png)

## Général

| Option | Description |
|--------|-------------|
| **Langue** | La langue de l'application : la langue du système (par défaut, l'anglais si ce n'est ni l'anglais ni le français), English ou Français. |
| **Thème** | Système (par défaut), Clair ou Sombre. |
| **Rouvrir le dernier site au démarrage** | Sinon, l'application s'ouvre sur la liste des sites. |

## Comptes

Les comptes d'hébergeurs utilisés pour publier vos sites : voir [Publication](publishing/index.md#comptes).

## Builds et preview

| Option | Description |
|--------|-------------|
| **Notifier la fin des builds** | Une notification système quand un build se termine ou échoue. |
| **Ouvrir le navigateur quand la preview est prête** | Pour les sites jamais prévisualisés : ensuite, chaque site garde sa propre [option de preview](build-preview-diagnosis.md#options-de-la-preview). |
| **Lignes affichées par défaut dans la sortie des builds** | Tout, étapes et problèmes, avertissements et erreurs, ou erreurs seulement. |

## Éditeur

| Option | Description |
|--------|-------------|
| **Retour à la ligne automatique** | Replie les longues lignes de l'éditeur Markdown. |
| **Taille du texte (px)** | De 10 à 24 (13 par défaut). |
| **Éditeur externe** | L'application qui ouvre les pages (**Ouvrir dans l'éditeur externe**) : **Choisir…** la sienne, ou **Réinitialiser** pour utiliser l'application par défaut du système pour le type de fichier. |

## Mises à jour

Affiche les versions de Cecil Desktop, de Cecil et de PHP, embarqués dans l'application, et **Rechercher des mises à jour**.

Sous Windows, Cecil Desktop télécharge ses mises à jour au démarrage. Quand l'une d'elles est prête, la barre d'état affiche **Mise à jour … prête** : cliquez dessus pour redémarrer et l'installer, sinon elle sera installée quand vous quitterez l'application. Chaque mise à jour embarque la dernière version de Cecil.

Sous macOS, les mises à jour automatiques ne sont pas encore disponibles : téléchargez la nouvelle version depuis le [site](/fr/#download), et installez-la par-dessus la précédente.
