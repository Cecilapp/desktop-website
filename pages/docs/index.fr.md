# Documentation de Cecil Desktop

Cecil Desktop est une application desktop pour gérer vos sites statiques [Cecil](https://cecil.app) : les créer, éditer leur contenu, les builder, les prévisualiser et les publier, sans taper une seule commande. PHP et Cecil sont embarqués : il n'y a rien d'autre à installer.

Vous découvrez Cecil Desktop ? Commencez par [Bien démarrer](getting-started.md) : installez l'application et ouvrez votre premier site en quelques minutes.

:::info
Cette documentation porte sur l'application. Pour comprendre le fonctionnement d'un site Cecil (contenu, templates, configuration), consultez la [documentation de Cecil](https://cecil.app/documentation/).
:::

## Aide et retours

Un bug, un manque ? Dans l'application, utilisez **Aide › Envoyer un retour…** : votre message est transmis à l'équipe, avec les versions de l'application et de votre système.
