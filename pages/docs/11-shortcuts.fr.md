# Raccourcis clavier

Les raccourcis des menus sont aussi affichés dans la [palette de commandes](getting-started.md#se-reperer) (`Ctrl/⌘+K`), à côté de chaque action.

## Menus

| Action | Windows | macOS |
|--------|---------|-------|
| **Fichier › Ouvrir un dossier…** | `Ctrl+O` | `⌘O` |
| **Fichier › Nouveau site…** | `Ctrl+N` | `⌘N` |
| **Fichier › Enregistrer** | `Ctrl+S` | `⌘S` |
| **Fichier › Préférences** | `Ctrl+,` | `⌘,` |
| **Site › Lancer ou ouvrir la preview** | `Ctrl+P` | `⌘P` |
| **Site › Builder** | `Ctrl+Maj+B` | `⌘⇧B` |
| **Site › Publier** | `Ctrl+Maj+P` | `⌘⇧P` |
| **Site › Ouvrir le dossier du site** | `Ctrl+Maj+E` | `⌘⇧E` |
| **Site › Aperçu** | `Ctrl+1` | `⌘1` |
| **Site › Contenu** | `Ctrl+2` | `⌘2` |
| **Site › Médias** | `Ctrl+3` | `⌘3` |
| **Site › Thèmes** | `Ctrl+4` | `⌘4` |
| **Site › Publication** | `Ctrl+5` | `⌘5` |
| **Site › Configuration** | `Ctrl+6` | `⌘6` |
| **Affichage › Palette de commandes…** | `Ctrl+K` | `⌘K` |
| **Affichage › Barre latérale** | `Ctrl+B` | `⌘B` |
| **Affichage › Panneau Sortie** | `Ctrl+J` | `⌘J` |
| **Affichage › Mode concentration** | `Ctrl+Maj+Entrée` | `⌘⇧Entrée` |

En [mode Rédaction](writing-mode.md), les sections que le rédacteur ne voit pas sont retirées, mais les autres gardent leur raccourci (par ex. `Ctrl/⌘+2` pour **Contenu**).

## Éditeur Markdown

| Action | Windows | macOS |
|--------|---------|-------|
| **Gras** | `Ctrl+B` | `⌘B` |
| *Italique* | `Ctrl+I` | `⌘I` |
| Code en ligne | `Ctrl+E` | `⌘E` |
| Quitter le mode concentration | `Échap` | `Échap` |

Dans l'éditeur, `Ctrl/⌘+B` met le texte en gras au lieu de replier la barre latérale.

## Panneaux

Les séparateurs entre les panneaux (arborescence des pages, éditeur, panneau Sortie…) se déplacent au clavier : donnez-leur le focus avec `Tab`, puis utilisez les flèches (avec `Maj` pour aller plus vite).
